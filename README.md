# Ume Translator

**Decode texts, flirt like a pro, and finally understand "I'm fine."**

Ume Translator is an AI assistant for dating and relationship texting. It reads a
message, explains what the other person actually means, and suggests how to reply.

> "K" → *"They're just busy, not mad. Reply with 'Miss you!'"*
> "I'm fine" after a fight → *"They're upset. Try 'Wanna talk about it?'"*

---

## The problem

Texting has taken over most of the communication in a relationship, but text lost
its tone of voice. "Whatever," "I'm good," "k." — any of them could mean anything,
and getting it wrong is expensive: a pointless argument, a conversation that dies,
a message that never gets a reply. People reread someone else's text ten times and
rewrite their own five. Ume takes the guesswork out.

## What it does

| Feature | What it does |
| --- | --- |
| **Decode Any Text** | Surfaces the meaning and emotion behind a message. "Whatever" → "They're mad, babe — don't sleep on this!" |
| **Flirt Mode** | Rewrites a flat reply into flirting without the cringe. "Nice chatting with you" → "Too much fun with you — consider me caught!" |
| **Context Clues** | Factors in the conversation so far. "I'm good" right after a fight doesn't read like "I'm good" out of nowhere |
| **Manipulation Radar** | Flags manipulative phrasing. "You always do this" → "Guilt trip alert — watch your step!" |

## Who it's for

- **Singles** — read mixed signals and decode dating-app messages
- **Couples** — understand your partner and stop starting fights over nothing
- **Flirt Fiends** — flirt with confidence and keep the conversation alive

## Blog

Alongside the product pages, the site publishes guides on texting and dating —
how to flirt over text without being awkward, what "I'm fine" really means, how
to keep a conversation going. Available at `/blog`.

## Stack

Vite 5 · React 18 · TypeScript · Tailwind CSS · React Router 6 · lucide-react

## Getting started

Requires Node.js 18+.

```bash
npm install
npm run dev      # http://localhost:8080
```

Other commands:

```bash
npm run build        # production build into dist/
npm run build:dev    # build in development mode
npm run preview      # serve the build locally
npm run lint         # ESLint
```
